<h2>📌 About The Project</h2>

<p>
  The <b>Password Generator Website</b> is a web-based application
  designed to generate random passwords quickly and easily. It provides
  a simple interface that helps users create passwords using different
  combinations of letters, numbers, and special characters.
</p>

<p>
  This project was created to practice frontend web development and
  understand JavaScript logic, functions, and interactive website design.
</p>

<h2>✨ Features</h2>

<ul>
  <li>🔐 Generate random passwords.</li>
  <li>🔠 Uppercase letter support.</li>
  <li>🔡 Lowercase letter support.</li>
  <li>🔢 Number support.</li>
  <li>🔣 Special character support.</li>
<li>📏 Customizable password length.</li>
